# Política de seguridad

Este repositorio documenta un laboratorio educativo local de WireGuard en VirtualBox.

- Nunca subas claves privadas, contraseñas, tokens ni configuraciones reales.
- Usa únicamente las plantillas `*.conf.example`.
- Revisa los cambios en GitHub Desktop antes de cada commit.
- Si una clave privada se publica por error, considérala comprometida, genera otra pareja y actualiza los peers.
- Borrar un secreto en un commit posterior no lo elimina necesariamente del historial Git.
